# Migration guide: v0.3.x → v1.0.0

The v1.0.0 release of `promptsheon` introduces **breaking changes**
under PLAN-49 / L-1. The legacy `sdk/` package is removed;
consumers must update their import path.

## What changed

| Old                                           | New                                              |
|-----------------------------------------------|--------------------------------------------------|
| `import "github.com/sachncs/promptsheon/sdk"`  | `import "github.com/sachncs/promptsheon/pkg/promptsheon"` |
| `ErrorApprovalCreatorVoted` etc.              | `ErrSelfVote` etc. (PLAN-49 c2.8)               |
| `store.Repositories`                           | `store.DB`                                       |
| `s.repos` (Server field)                      | `s.db`                                           |

## What did NOT change

- HTTP API surface (every endpoint, every request/response shape)
- Authentication (`ps_<hex>` API key format)
- Database schema (migrations are backward-compatible through v1.x)
- Helm chart values (some defaults tightened, but values are
  compatible)

## Migration steps (Go)

```diff
- import sdk "github.com/sachncs/promptsheon/sdk"
+ import "github.com/sachncs/promptsheon/pkg/promptsheon"

  func main() {
-     c := sdk.New("https://api.promptsheon.dev", apiKey)
+     c := promptsheon.New("https://api.promptsheon.dev", apiKey)
      list, err := c.ListWorkspaces(ctx)
-     if errors.Is(err, sdk.ErrStoreNotFound) { ... }
+     if errors.Is(err, promptsheon.ErrStoreNotFound) { ... }
  }
```

The build flag `-tags=promptsheon` is required for any code that
imports `pkg/promptsheon/`. The Makefile targets `build-public`
and `check-public` set this for you.

## Migration steps (Python / TypeScript)

**There are no Python or TypeScript migration steps** because
those SDKs do not ship as of v1.0.0. The `sdk/python/` and
`sdk/typescript/` directories were removed in PR-4 of
`docs/research/audit-fixes-plan.md` — they contained only a
copy of the OpenAPI spec and no actual client code. The README,
ROADMAP, and CI all advertised SDKs that did not exist as
runnable code; the directories are now gone.

If a future release re-introduces the Python or TypeScript
SDKs via a generator pass, this section will document the
migration path. Until then, the only SDK surface is the Go
client at `pkg/promptsheon`.

## Codemod

For Go projects with many import statements to update, a
codemod is available at `tools/codemod-sdktopkgshe-on/`. Run:

```bash
go run ./tools/codemod-sdktopkgshe-on/ ./...
```

The codemod:
- Replaces `import "github.com/sachncs/promptsheon/sdk"` →
  `import "github.com/sachncs/promptsheon/pkg/promptsheon"`
- Renames local `sdk.X` identifiers to `promptsheon.X` when used
- Leaves non-import `sdk` references (e.g. `log/slog` or a local
  variable named `sdk`) alone

## Timeline

- **v1.0.0 (this release):** `sdk/` removed; `pkg/promptsheon/` is
  the only public Go SDK.
- **v1.0.x:** bug-fix releases will not bring `sdk/` back.
- **v2.0.0:** no planned API changes; this migration is one-time.
