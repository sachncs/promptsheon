## Cross-Cutting Themes

1. **Concurrency races** — TOCTOU between read/write, atomic block checks, lock-then-act-inconsistently. Affects `promptsheon/cas`, `backend`, `promptsheon/invoke`, `promptsheon/election`, `promptsheon/evolve`, `promptsheon/store`, `promptsheon/eventbus`, `promptsheon/ratelimit`, `promptsheon/redactor`, `promptsheon/metrics`, `promptsheon/guardrail`.
2. **Atomicity / transactional integrity** — partial writes between object, ref, HEAD, audit, release. Affects `promptsheon/cas`, `promptsheon/store`, `promptsheon/release`, `promptsheon/evolve`, `promptsheon/rollups`.
3. **Raw errors leaked to clients** — `err.Error()` echoed in HTTP responses, including provider SDK errors. Affects `backend` (10+ handlers), `promptsheon/llm` (judge), `promptsheon/guardrail`.
4. **Missing multi-tenant isolation** — no workspace ACL across `handleGet*` / `handleCreate*` paths.
5. **Missing size/rate limits** — decompression bombs, unbounded audit export, no body limits. Affects `promptsheon/cas`, `backend`, `promptsheon/vault`.
6. **Predictable / weak IDs** — `UnixNano()`, time-derived IDs, no `crypto/rand`. Affects `promptsheon/executor`, `promptsheon/evolve`, `promptsheon/guardrail`, `promptsheon/alerting`.
7. **Sync `pkg` globals + init-time config** — `init()` reads env, package-level mutable state, test contamination.
8. **Critical paths missing panic recovery** — audit workers, executor goroutines, evolver, WebSocket handlers, eventbus subscribers.
9. **Outdated / incorrect GoDoc** — claims that don't match implementation.
10. **Dead/unreachable code** — `Authorizer`, `ErrAlreadyCanceled`, `judgeCache`, `mergeCIDRs`, `_ = showVersion`, `parseFloat64` mutable global, `errIs` hand-rolled.
