# Reasoning Compiler SOP

## Parameters
- raw_prompt (REQUIRED): The raw system prompt to compile
- capability_context (OPTIONAL): Additional context about the capability
- constraints (OPTIONAL): Specific constraints to apply

## Steps

### Step 1: Analyze Intent
- MUST understand the core task the prompt is designed for
- SHOULD identify edge cases and failure modes
- MAY request clarification if ambiguous

### Step 2: Add Reasoning Steps
- MUST break down complex tasks into numbered steps
- SHOULD include decision points and branching logic
- MUST specify what to do when uncertain

### Step 3: Add Error Handling
- MUST define how to handle invalid inputs
- SHOULD specify retry behavior for transient failures
- MUST include fallback responses

### Step 4: Optimize Output

### `packages/server/src/agents/compiler.ts`
```typescript
import { Agent } from '@strands-agents/sdk';
import type { AppConfig, Manifest } from '@promptsheon/shared';
import { REASONING_COMPILER_SYSTEM_PROMPT, REASONING_COMPILER_SOP } from './compiler/prompts';

export class ReasoningCompiler {
  private agent: Agent;

  constructor(config: AppConfig) {
    this.agent = new Agent({
      model: createModel(config),
      systemPrompt: REASONING_COMPILER_SYSTEM_PROMPT,
    });
  }

  async compile(
    manifest: Manifest,
    options: {
      capabilityContext?: string;
      constraints?: string[];
    } = {},
  ): Promise<Manifest> {
    const prompt = `
# Raw System Prompt
${manifest.systemPrompt}

# Capability Context
${options.capabilityContext ?? 'None'}

# Constraints
${options.constraints?.join('\n') ?? 'None'}

# Task
Compile this prompt following the reasoning compiler SOP.
Output the compiled prompt as a JSON object with the same structure as the input.
`;

    const result = await this.agent.invoke(prompt);
    const compiled = JSON.parse(result.message);

    return {
      ...manifest,
      systemPrompt: compiled.systemPrompt ?? manifest.systemPrompt,
      metadata: {
        ...manifest.metadata,
        compiled: true,
        compiledAt: new Date().toISOString(),
        originalHash: await hashManifest(manifest),
      },
    };
  }

  async decompile(compiledManifest: Manifest): Promise<string> {
    // Extract the original reasoning from compiled prompt
    const prompt = `
# Compiled Prompt
${compiledManifest.systemPrompt}

# Task
Extract the original user-facing prompt from this compiled prompt.
Output just the prompt text, no JSON.
`;

    const result = await this.agent.invoke(prompt);
    return result.message;
  }
}
```
