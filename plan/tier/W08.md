## Files to Create

Each repo follows this pattern:
```typescript
import type Database from 'better-sqlite3';
import type { EntityType } from '@promptsheon/shared';
import { notFound, conflict } from '@promptsheon/shared';

export class EntityRepo {
  constructor(private db: Database.Database) {}

  async findById(id: string): Promise<EntityType | null> {
    return this.db.prepare('SELECT * FROM entities WHERE id = ?').get(id) as EntityType | null;
  }

  async findMany(opts: { page: number; pageSize: number }): Promise<{ items: EntityType[]; total: number }> {
    const total = (this.db.prepare('SELECT COUNT(*) as count FROM entities').get() as any).count;
    const items = this.db.prepare('SELECT * FROM entities LIMIT ? OFFSET ?')
      .all(opts.pageSize, (opts.page - 1) * opts.pageSize) as EntityType[];
    return { items, total };
  }

  async create(data: Omit<EntityType, 'id' | 'createdAt' | 'updatedAt'>): Promise<EntityType> {
    const id = crypto.randomUUID();
    const now = new Date().toISOString();
    // INSERT prepared statement
    return { id, ...data, createdAt: now, updatedAt: now } as EntityType;
  }

  async update(id: string, data: Partial<EntityType>): Promise<EntityType> {
    const existing = await this.findById(id);
    if (!existing) throw notFound('entity', id);
    // UPDATE prepared statement
    return { ...existing, ...data, updatedAt: new Date().toISOString() } as EntityType;
  }

  async delete(id: string): Promise<void> {
    const existing = await this.findById(id);
    if (!existing) throw notFound('entity', id);
    // DELETE prepared statement
  }
}
```

### Repo-Specific Patterns

**WorkspaceRepo**: CRUD only
**ProjectRepo**: CRUD + `findByWorkspaceId(workspaceId)`
**CapabilityRepo**: CRUD + `findByProjectId(projectId)` + self-evolve fields
**VersionRepo**: CRUD + `findByCapabilityId(capabilityId)` + `findByCapabilityAndVersion(capabilityId, version)`
**ReleaseRepo**: CRUD + `findByCapabilityAndEnv(capabilityId, env)` + `findActive(capabilityId, env)` + status transitions
**ExecutionRepo**: CRUD + `findByVersionId(versionId, opts)` + `findRecent(capabilityId)`
**DatasetRepo**: CRUD + `findByCapabilityId(capabilityId)`
**EvalRepo**: CRUD + `findByReleaseId(releaseId)` + `findResultsByRunId(runId)`
**PreconditionRepo**: CRUD + `findByCapabilityId(capabilityId)`
**AlertRepo**: CRUD + `findByStatus(status)` + `findByRuleId(ruleId)`
**ScheduleRepo**: CRUD + `findDueSchedules(now)` + `findByReleaseId(releaseId)`
**UserRepo**: CRUD + `findByEmail(email)`
**ApiKeyRepo**: CRUD + `findByUserId(userId)` + `findByKeyHash(hash)`
**ProviderKeyRepo**: CRUD + `findByProvider(providerName)`
**WebhookRepo**: CRUD + `findByEvent(event)`
**FeatureFlagRepo**: `get(name)` + `setEnabled(name, enabled)`
**RecommendationRepo**: CRUD + `findByVersionId(versionId)`
**LineageRepo**: CRUD + `findByCapabilityId(capabilityId)` + `findByParent(capabilityId, version)` + `findByChild(capabilityId, version)`
**ApprovalRepo**: `getByReleaseId(releaseId)` + `upsert(releaseId, votes)`
**SelfEvolveRepo**: `getByCapabilityAndEnv(capabilityId, env)` + `upsert(state)`
**CapabilityContractRepo**: `getByCapabilityId(capabilityId)` + `upsert(contract)`
**EnforcerRepo**: `get(workspaceId, kind)` + `upsert(state)`
**SystemConfigRepo**: CRDT operations (get, set, merge, list)
**NotificationGroupRepo**: CRUD + `findByAlertRuleId(ruleId)`
**AuditArchiveRepo**: `archive(olderThan)` + `search(opts)`
**IdempotencyRepo**: `get(key)` + `set(key, response, expiresAt)` + `cleanup()`
**VaultRepo**: singleton get/set
**WsStateRepo**: singleton get/nextId
**BanditRepo**: `get(armId, replicaId)` + `increment(armId, replicaId, success)`

## Acceptance Criteria

- [ ] Every repo has CRUD for its table
- [ ] All prepared statements use parameterized queries (no SQL injection)
- [ ] `findById` returns null for missing records (not error)
- [ ] `create` generates UUID, sets timestamps
- [ ] `update` throws `notFound` for missing records
- [ ] `delete` throws `notFound` for missing records
- [ ] Pagination follows `{ items, total }` pattern
- [ ] All repos accept `Database` in constructor (dependency injection)
- [ ] No repo imports route handlers or agents
- [ ] All queries are synchronous (better-sqlite3 is sync)
- [ ] Complex queries (joins, aggregations) use raw SQL
- [ ] Foreign key constraints are respected
