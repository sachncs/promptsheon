## Input Contract

## Output Contract

Exports consumed by ALL other work units:
- Domain model types (Workspace, Project, Capability, Version, Manifest, Release, Deployment, Execution)
- Zod validation schemas for all API request/response shapes
- Error code enum + error response type
- Constants (environments, statuses, roles, limits)

## Acceptance Criteria

- [ ] All type files compile with `tsc --noEmit`
- [ ] Every DB table has a corresponding TypeScript interface
- [ ] Every Zod schema validates correctly (unit tests)
- [ ] All constants match Go codebase values
- [ ] Error codes match Go `errs/errors.go` sentinels
- [ ] Barrel exports work from `@promptsheon/shared`
- [ ] No circular dependencies between type files
- [ ] All fields use camelCase (not snake_case)
- [ ] All date fields are ISO 8601 strings
- [ ] All JSON fields are typed as `string` with JSON docs
